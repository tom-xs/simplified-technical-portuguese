# Regras Gramaticais e de Estrutura

> **Origem metodológica:** as regras R1–R6 são adaptadas do ASD-STE100 (Simplified Technical English) para o português brasileiro. Foram mantidos apenas os princípios independentes de idioma (frase curta, ordem direta, voz ativa, uma ideia por frase). As regras do STE100 específicas do inglês — dicionário aprovado de palavras, restrições a formas "-ing", uso de artigos, phrasal verbs — não se aplicam ao pt-BR e foram excluídas. A autoridade normativa para o português são a Lei 15.263/2025, a NBR ISO 24495-1 e o Manual de Redação da Presidência da República (ver [fontes.md](fontes.md)).

## 1. Estrutura de frases

| Regra | Instrução | Exemplo correto | Exemplo incorreto |
| --- | --- | --- | --- |
| R1 | Use frases curtas (máximo 25 palavras). | "O sistema verifica a conexão." | "O sistema realiza uma verificação da conexão de rede para garantir que a comunicação esteja estabelecida de forma adequada." |
| R2 | Prefira a ordem direta: Sujeito + Verbo + Predicado. | "O usuário insere a senha." | "Insere o usuário a senha." |
| R3 | Use voz ativa sempre que possível. | "O programa executa a tarefa." | "A tarefa é executada pelo programa." |
| R4 | Uma ideia por frase. | "O arquivo foi salvo. O backup iniciou." | "O arquivo foi salvo e o backup foi iniciado automaticamente pelo sistema." |
| R5 | Uma ideia por parágrafo. | Parágrafo 1: Instalação. Parágrafo 2: Configuração. | Parágrafo único misturando instalação, configuração e uso. |
| R6 | Evite orações subordinadas excessivas. | "O relatório será gerado após a validação." | "O relatório, que será gerado pelo sistema, será disponibilizado ao usuário assim que a validação dos dados, que ocorre em segundo plano, for concluída." |

## 2. Tempo verbal

- Use o presente para descrever procedimentos e funcionalidades.
- Use o futuro apenas quando necessário.
- Mantenha o mesmo tempo verbal por seção.

## 3. Pontuação

- Use ponto final para separar ideias completas.
- Use dois-pontos para introduzir listas.
- Use ponto e vírgula apenas quando indispensável.
- Evite excesso de vírgulas que fragmentem a leitura.

## 4. Ritmo e variação (anti-detecção de IA)

Detectores de IA identificam textos não por palavras isoladas, mas pela **densidade de padrões previsíveis**. Para evitar:

- Varie o comprimento das frases dentro do limite de 25 palavras. Não faça todas com 12-15 palavras.
- Alterne entre frases simples e compostas curtas.
- Inclua detalhes concretos: números, nomes de arquivos, versões, unidades.
- Evite a cadência "tema → 3 exemplos → conclusão" em todo parágrafo.

## 5. Estrutura recomendada para textos técnicos

### 5.1 Instruções / procedimentos

1. Título claro e objetivo.
2. Breve descrição do objetivo (1-2 frases).
3. Lista numerada de passos, um por item.
4. Observações (se necessário), em bloco separado.

### 5.2 Explicações / conceitos

1. Definição direta (1 frase).
2. Desenvolvimento com exemplos concretos.
3. Aplicação prática.

### 5.3 Respostas a perguntas

1. Resposta direta na primeira frase.
2. Desenvolvimento com detalhes, se necessário.
3. Evite rodeios antes da resposta.

## 6. Limites tipográficos (referência jornalística)

Baseado no Manual de Redação do Estadão e em guias de linguagem simples:

- Períodos: até 2-3 linhas (aprox. 25 palavras).
- Parágrafos: média de 5 linhas, máximo de 8.
- Use intertítulos a cada 3-5 parágrafos em textos longos.
- Coloque a informação mais importante no início (pirâmide invertida).
