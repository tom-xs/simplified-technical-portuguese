# Vocabulário Controlado

## 1. Palavras permitidas

- Use palavras de uso comum no português brasileiro.
- Prefira verbos de ação concretos: "fazer", "verificar", "executar", "salvar", "enviar", "receber".
- Use substantivos concretos e mensuráveis.

## 2. Palavras proibidas / restritas

| Categoria | Proibição | Exemplo de jargão | Substituição |
| --- | --- | --- | --- |
| Jargão de IA | Evite termos que revelem natureza artificial. | "Como modelo de linguagem", "minha base de conhecimento", "fui treinado em dados até" | Omitir ou reformular. |
| Meta-referência | Não fale sobre si mesmo como IA. | "Não posso", "Não tenho acesso", "Minhas limitações" | "Não há informações disponíveis." |
| Eufemismos de IA | Evite rodeios para negar ou admitir incerteza. | "Não tenho certeza, mas...", "Pode ser que...", "Acredito que..." | "Os dados indicam que..." ou "Não há confirmação." |
| Estrangeirismos | Evite palavras estrangeiras não consagradas. | "deploy", "workaround", "feedback", "overview" | "implantação", "solução alternativa", "retorno", "visão geral" |
| Neologismos de IA | Evite termos da cultura digital exagerados. | "disruptivo", "sinergia", "ecossistema" (fora de contexto biológico), "jornada do usuário" | "inovador", "cooperação", "conjunto de sistemas", "processo de uso" |
| Abstrações excessivas | Evite substantivos abstratos onde haja verbo. | "realização de uma análise" | "analisar" |
| Redundâncias | Evite pleonasmos. | "certeza absoluta", "detalhes minuciosos", "retornar de volta", "o motivo é porque" | "certeza", "detalhes", "retornar", "o motivo é que" |
| Burocratismos | Evite linguagem burocrática. | "no que tange a", "no tocante a", "a quo", "ad quem", "face a" | "sobre", "em relação a", "de", "para", "diante de" |

## 3. Termos técnicos

- Permita termos técnicos apenas quando indispensáveis.
- Na primeira ocorrência, escreva o nome por extenso seguido da sigla entre parênteses.
- Forneça uma breve explicação do termo técnico no próprio texto.
- Exemplo: "O sistema usa um **banco de dados relacional** (SGBD), que organiza as informações em tabelas interligadas."

## 4. Estrangeirismos consagrados (permitidos)

Termos já incorporados ao português técnico brasileiro podem ser usados sem tradução: "software", "hardware", "link", "site", "e-mail", "download", "upload", "mouse", "login", "senha". Em dúvida, consulte o Vocabulário Ortográfico da Língua Portuguesa (VOLP) da ABL.

## 5. Substituições comuns adicionais

| Evite | Prefira |
| --- | --- |
| "a fim de" | "para" |
| "com o intuito de" | "para" |
| "por meio de" (abusivo) | "por", "com", "através de" (conforme o caso) |
| "no sentido de" | "para", "a fim de" |
| "em virtude de" | "por causa de", "devido a" |
| "realizar" (abstrato) | verbo específico: "fazer", "executar", "criar" |
| "efetuar" | "fazer", "pagar", "realizar" |
| "possibilitar" | "permitir" |
| "viabilizar" | "permitir", "tornar possível" |
| "impactar" (verbo) | "afetar" |
| "otimizar" (abusivo) | "melhorar", "agilizar" |
